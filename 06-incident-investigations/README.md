# Incident Investigations

This folder contains investigation reports created from completed SOC detection labs.

Each investigation will document:

- Incident summary
- Timeline
- Evidence
- Affected host
- User activity
- Suspicious indicators
- Investigation process
- MITRE ATT&CK mapping
- Detection logic
- Conclusion
- Recommended response

## Status

No formal incident investigations have been completed yet.

Future investigations will be added after controlled lab scenarios are performed and analyzed.

## Screenshot Guidance

Use names such as:

```text
01-kali-connectivity.png
02-windows-event-viewer.png
03-wazuh-agent-connected.png
04-sysmon-event-id-1.png
05-splunk-security-events.png
```

Screenshots should prove lab connectivity, Wazuh agent operation, Sysmon events, process investigations, DNS events, Splunk ingestion, SPL results, or detection results. Avoid passwords, tokens, API keys, personal information, and unnecessary full-screen captures.
