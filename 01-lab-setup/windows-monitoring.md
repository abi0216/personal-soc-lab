# Windows Monitoring Setup

## Purpose

The Windows machine acts as the monitored endpoint in the SOC lab. Security telemetry generated on Windows is collected and analyzed using Wazuh and Splunk.

## Monitoring Components

The Windows machine generates telemetry through:

- Windows Event Logs
- Sysmon

The telemetry is monitored using:

- Wazuh
- Splunk Enterprise

## Important Windows Log Sources

The lab collects Windows Event Logs including:

- Security
- System
- Application
- Setup

The Security log is particularly important for SOC investigations because it contains authentication and security-related events.

## Sysmon

Sysmon provides detailed endpoint telemetry, including:

- Process creation
- File creation
- DNS queries
- Network connections

## Monitoring Flow

```text
Windows Activity
	|
Windows Event Logs + Sysmon
	|
Monitoring Platform
	|
SOC Investigation
```

## Key Learning

A SOC analyst does not directly observe every attacker action. The analyst investigates evidence generated by the operating system and security monitoring tools.
